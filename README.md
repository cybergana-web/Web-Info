💀 WebInfo - Advanced Reconnaissance Toolkit

WebInfo is a powerful Python-based CLI reconnaissance tool that provides multiple information-gathering techniques in one place. It is specifically designed for beginners and intermediate cybersecurity enthusiasts.

---

## 🚀 Features

* 🔍 IP Lookup
* 🌐 DNS Lookup
* 📡 WHOIS Lookup
* 🚪 Port Scanning
* 🧠 Website Information Gathering
* 📑 HTTP Headers Analysis
* 🌍 Subdomain Scanning
* 💾 Save Results Option
* 🎯 Clean Hacker Style CLI Interface

---

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/argcyberskillhub-commits/WebInfo.git
cd WebInfo
```

### 2. Install Requirements

```bash
pip install -r requirements.txt
```

---

## ▶️ Usage

```bash
python WebInfo.py
```
